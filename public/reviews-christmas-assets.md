# Christmas scene layers

The current background and transparent sleigh layers were prepared from the latest user-supplied moon/cloud reference using image editing. They are faithful visual reconstructions, not the original reference file or a claim of pixel-for-pixel identity. Cloud placement, ivory lunar lighting, dense stars and diagonal sleigh arrangement follow that reference. Original preparation files are preserved in the execution workspace; optimized WebP copies are served locally by the website.

The earlier NASA/pine/SVG treatment is superseded and is not rendered.
